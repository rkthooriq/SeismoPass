# Panduan Pengguna — Demo Landing Page

## Status dan Batasan

Panduan ini mengikuti kode tampilan awal, belum diverifikasi lewat browser atau UAT. Demo tidak menyimpan data, menyediakan akun, atau melakukan screening. RVS merupakan penyaringan awal, bukan sertifikat aman.

## Menjelajahi Halaman

1. Buka alamat aplikasi setelah lingkungan berhasil dijalankan sesuai README.
2. Pada HP, tekan **Menu** untuk menampilkan navigasi; tekan **Tutup** untuk menyembunyikannya. Pada layar lebar, navigasi ditampilkan langsung.
3. Pilih **Jelajahi SeismoPass** untuk menuju area demo.
4. Pilih **Contoh profil** atau **Buka contoh profil** untuk melihat data fiktif Rumah Contoh A. Status **Belum dinilai** berarti hasil belum tersedia, bukan kategori risiko.
5. Pilih **Ilustrasi** untuk kembali ke ilustrasi bangunan.
6. Pilih **Cara kerja** untuk membaca enam tahap yang direncanakan.
7. Baca bagian **Screening awal. Bukan sertifikat aman.**
8. Pada bagian pertanyaan, pilih pertanyaan untuk membuka/menutup jawabannya.

## Jika Ada Masalah

Jika halaman tidak muncul, periksa instruksi Docker dan status server di README. Jika teks terpotong atau navigasi tidak bekerja, catat ukuran layar, browser, langkah, serta hasil yang diharapkan/aktual. Jangan menyertakan data pribadi atau token dalam laporan. Kontak dukungan belum ditetapkan.

## Pengujian Pemahaman yang Direncanakan

Minta peserta mengikuti panduan tanpa dituntun, menemukan contoh profil, dan menjelaskan arti “belum dinilai” serta keterbatasan RVS. Panduan dan hasil pemahaman ini belum dinyatakan lulus UAT. Tangkapan layar ditambahkan setelah pratinjau tersedia.
