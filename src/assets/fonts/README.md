# Font SeismoPass

Figtree digunakan untuk judul dan Inter untuk teks, mengikuti keluarga font pada CSS Evernote Enterprise yang diperiksa 11 November 2026. Keduanya disajikan dari aset lokal, dengan `font-display: swap` dan font fallback.

Sumber: repositori resmi Google Fonts, `ofl/figtree/Figtree[wght].ttf` dan `ofl/inter/Inter[opsz,wght].ttf` pada https://github.com/google/fonts. Lisensi SIL Open Font License 1.1 disertakan pada `Figtree-OFL.txt` dan `Inter-OFL.txt`.

`../plan-pattern.svg` adalah corak denah dekoratif orisinal untuk SeismoPass, bukan denah atau hasil pemeriksaan bangunan nyata.
